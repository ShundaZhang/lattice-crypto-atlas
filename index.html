03 / THE MINIMUM MODEL

先记住四个不变量。

网站各章都围绕这些关系展开。它们是帮助理解的模型，不能直接当成生产密码实现。

01 / SET

格是点集，基是描述

Λ(B) 由整数线性组合生成。换一组行列式为 ±1 的整数基变换，可能得到同一个格。

02 / HARDNESS

低维图像不等于高维安全

二维可枚举；真实参数要面对最佳已知攻击和所需资源。不能只靠 qⁿ 的暴力搜索量级判断安全。

03 / NOISE

噪声同时约束两端

LWE 的噪声阻止直接解方程，但解码余量有限。参数必须兼顾困难性和正确性。

04 / INTERFACE

KEM 与签名不是一回事

ML-KEM 建立共享秘密；ML-DSA 对消息签名。KEM 本身不证明对端身份。

05 / STRUCTURE

Module 是效率与假设的取舍

多项式结构压缩表示、提升速度；安全论证必须对应具体的模块问题与参数。

06 / IMPLEMENTATION

算法安全不自动延伸到代码

分布、随机数、解封装失败处理、常数时间和故障防护会改变系统安全性。
