01 / BASIS EXPLORER

改变基，不改变格。

拖动滑块，第二个基向量越来越倾斜。背景中的 ℤ² 格点保持原样；这就是“格是集合、基是描述”的可视化。

同一个 ℤ²，不同的 B

短而正交长而倾斜
b₁=(1,0) · b₂=(0,1) · |det B|=1

观察三件事

  • 任意 k∈ℤ，b₁=(1,0)、b₂=(k,1) 的行列式都为 1。
  • 因为 (0,1)=b₂−k·b₁，第二组仍可生成所有整数点。
  • 向量 b₂ 越长，图上的基越倾斜；这张二维图不证明高维密码安全。
注意模型范围

“公钥坏基、私钥好基”适合早期格密码的直觉。ML-KEM 的公私钥结构不同，不能直接套这张图。

02 / TOY DECODING

噪声帮助隐藏信息，
也可能破坏解码。

这个模型只展示“消去主要结构后如何判读一个 bit”。它不模拟 LWE 攻击成本，也不实现 ML-KEM。

模 17 的一个解码位置

bit 0 编码在 0 附近，bit 1 编码在 8 附近。调节残余噪声 e，观察得到的 phase 和最近的编码中心。

−50+5
0
phase=(0+0) mod 17 = 0 → 解出 bit 0，正确

为什么它不是密码实现？

  • 模型直接暴露原始 bit 和残余噪声，只用于说明正确性阈值。
  • 真实 LWE 要考虑 secret、样本、噪声分布、攻击与失败概率；不是一个滑块决定安全。
  • 真实 KEM 还要处理编码、随机数、解封装失败、选择密文攻击与协议认证。
继续推导

toy 代码中 u=Aᵀr、v=bᵀr+bit·⌊q/2⌋。利用 b=As+e，可得 v−sᵀu=eᵀr+bit·⌊q/2⌋。
